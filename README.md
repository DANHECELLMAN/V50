# 喵勇者：花园大作战

根据《猫咪轻量动作肉鸽_总体策划案 V1.0》制作的首个可玩纵向切片。项目为零依赖 HTML5 Canvas 游戏，可直接双击 `index.html` 运行。

## 已完成内容

- 只移动、自动瞄准和自动攻击；支持 WASD、方向键和触屏虚拟摇杆
- 默认 8 分钟完整节奏：快速成型 → 中压构筑 → 高压怪潮 → Boss
- 4 把武器、8 个被动、2 个固定装置，升级固定三选一并有 2 次刷新
- 6 类普通/特殊敌人、精英怪、两阶段 Boss“暴走扫地机”
- 经验球、金币、治疗、宝箱、商人、随机事件和结算战报
- 响应式横竖屏布局、本地最高存活时间与猫币存档
- 纯 Canvas Q 版占位美术与 Web Audio 合成反馈，不依赖外部素材

## 运行

直接打开 `index.html`，或在本目录启动任意静态文件服务器。

## 操作

- 电脑：WASD / 方向键移动，`P` 或 `Esc` 暂停
- 手机：拖动左下角虚拟摇杆
- 武器自动攻击；升级、商店、事件界面会自动暂停战斗

## 开发测试模式

开发测试功能仅用于玩法、Build、数值、怪潮和 Boss 验证，不属于正式玩家内容。

- 首页点击“开发测试”可直接进入测试局并自动打开右侧 `DEV LAB`。
- 通过静态服务器运行时，也可在地址后追加 `?dev=1` 自动进入，例如 `http://127.0.0.1:4173/?dev=1`。
- 开发测试角色初始生命较高，但不会自动获得满级 Build。
- `DEV LAB` 支持模拟暂停、0.5/1/2/4 倍速、无敌、无限刷新、玩家参数编辑，以及动态武器/被动/装置等级控制。
- 可直接生成普通敌人、精英潮和 Boss，切换 Boss 阶段与生命，跳转前中后期，打开升级、商店、宝箱和随机事件。
- 内置 Early/Mid/Late/Boss/Max Build/Stress Test 六个测试预设，并显示 FPS、DPS、敌人和投射物等实时统计。
- Build 可保存到浏览器 `localStorage` 的 `meowGardenDevBuilds.v1`，提供 Slot 1–3；也可复制或导入精简 JSON。
- 开发模式的金币、击杀和结算奖励不会写入正式 `meowGardenProfile` 存档。

关闭 `DEV LAB` 后恢复游戏；面板打开时默认暂停，也可以保持面板打开并点击“继续”观察实时统计。

## 当前版本边界

本次交付对应策划案 P1 纵向切片，优先验证核心移动手感、怪潮节奏、Build 选择和 Boss 可读性。三角色、其余两张主线地图、专属挑战、局外成长树、广告及完整首发内容池属于后续里程碑。
