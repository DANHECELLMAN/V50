# 喵勇者：墨韵庭院

根据动漫水墨风系列规格持续开发的 HTML5 可玩原型，当前用于验证玩法、Build、数值、Boss 与怪潮。

## 技术结构

- 不使用 Canvas；战斗场景、角色、敌人、弹体、掉落与特效全部使用 HTML DOM + CSS 呈现。
- 角色、武器、敌人、Boss 与美术引用集中在 `game-data.js`，数值逻辑与表现资源分离。
- 美术图片位于 `assets/art/`，可以在不改伤害公式的情况下替换。
- 零第三方依赖，使用静态服务器即可运行。

## 当前内容

- 三角色使用统一数据结构：墨小白（可出战）、赤痕（开发中）、青砚（开发中）。
- 墨小白为当前正式可玩角色，保留移动、自动瞄准、自动攻击、6 武器槽和固定装置结构。
- 赤痕已经预留九命、复活衰减、永久增益与挡伤护盾配置；青砚已经预留武器槽、召唤槽、伙伴能量和独立召唤物成长配置。本轮仅展示，不启用未完成机制。
- 已接入完整 12 把水墨武器：鱼骨墨针、流叶回锋、爪痕剑气、铃线追魂、泼墨团、扇骨游刃、残墨雾、水纹震、符墨阵、雷墨丝、回游鱼刃、狮吼墨波。
- 12 把武器均支持 Lv.1～Lv.7 数值成长、专属行为与终极变化；DEV LAB 会直接读取武器数据自动生成控制项。
- 两个固定装置：镇纸飞刃、纸伞震阵。
- 小墨灵、疾影鼠、石墨兽、墨羽鸦、铃纸灵、残墨妖与赤印精英。
- 两阶段首领“泼墨狸将”：扇形泼墨弹 + 毛笔落地危险墨痕。
- 三选一升级、Lv.7 终极变化、商店、奇遇、宝箱、暂停、结算和本地存档。
- 独立开发测试面板，支持改数值、刷怪、跳阶段、召唤 Boss 与保存 Build。

## 运行

在本目录启动任意静态文件服务器后访问 `index.html`。也可以直接双击页面运行；静态服务器模式在浏览器兼容性上更稳定。

## 操作

- 电脑：WASD / 方向键移动，`P` 或 `Esc` 暂停。
- 手机：拖动左下角虚拟摇杆。
- 武器自动攻击；升级、商店和事件界面会自动暂停战斗。

## 开发测试

- 首页点击“开发测试”，或访问 `index.html?dev=1`。
- 点击右上角“DEV ⚙”打开或关闭开发测试台；面板打开时默认暂停战斗。
- DEV LAB 支持运行速度、无敌、无限刷新、玩家属性、全部武器/被动/装置等级、刷怪、Boss、流程阶段、测试预设、实时统计、Build 保存/导入以及战场清理。
- Build 的 Slot 1～3 与当前配置保存在浏览器 `localStorage` 中，仅在当前浏览器和当前页面来源下可用。
- 开发模式数据不会写入正式存档。

## 首页与视觉方向

- 首页采用“Q 版动漫 + 水墨表现”：PC 为左侧功能、中央角色、右侧角色与章节信息；手机端调整为角色、章节、主按钮、功能入口的纵向结构。
- 首页入口包括角色、成长、武器、挑战、设置和存档；没有加入联网大厅、商城、活动或社交入口。
- 角色界面可以预览三名角色，开发中角色不能进入正式战斗。

## 表现层替换

- `game-data.js` 中提供 `LEGACY_ASSET_MAP`，正式动漫水墨素材使用新的 `art_key`，旧素材保留为 `fallback_art` / `legacy_art`。
- 页面会优先尝试加载新素材；文件尚未制作时自动回退到现有素材，不会中断游戏。
- `INK_FX` 为统一水墨 FX 接口，当前提供笔锋、墨花、流动墨线、水纹、墨池和退墨等表现类型，并限制粒子数量保证战斗可读性。
- 后续替换素材时优先在 `assets/art/` 增加对应新文件，或修改数据中的 `art` / `fallback_art` / `fx_id`，不要用中文显示名判断战斗规则。
