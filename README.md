# 喵勇者：墨韵庭院

根据动漫水墨风系列规格持续开发的 HTML5 可玩原型，当前用于验证玩法、Build、数值、Boss 与怪潮。

## 技术结构

- 不使用 Canvas；战斗场景、角色、敌人、弹体、掉落与特效全部使用 HTML DOM + CSS 呈现。
- 角色、武器、敌人、Boss 与美术引用集中在 `game-data.js`，数值逻辑与表现资源分离。
- 美术图片位于 `assets/art/`，可以在不改伤害公式的情况下替换。
- 零第三方依赖，使用静态服务器即可运行。

## 当前内容

- 三角色使用统一数据结构并均可选择出战：喵小白、赤痕、青砚。
- 喵小白现为默认初始角色，并接入四方向移动、攻击、受击和死亡动画；停止时保留最后朝向并回到该方向首帧。角色图片使用固定脚底锚点，碰撞体仍独立沿用原有数值。
- 赤痕已实装“赤痕裂爪”“断命突进”“九命复生”“墨环护命”和越死越强；技能树可继续解锁余火、盾破墨爆、追命必暴、死斗印记、不屈残火与复活视觉进化。
- 青砚已实装墨鼠机关、纸鹤群、石甲犬灵三类独立属性伙伴，以及伙伴能量、阵亡联动、回墨号令和砚光护阵。三类伙伴已改用独立水墨形象，并具有 Lv.1 / Lv.3 / Lv.5 视觉阶段；召唤伤害不会继承玩家攻击、暴击、攻速和范围。
- 已按《三角色技能树 V2》搭建 44 个数据驱动节点：喵小白 14 个、赤痕 14 个、青砚 16 个，包含前置链、铜钱成本、机制、VFX、卡池、槽位、挑战和最终二选一突破。
- 已接入完整 12 把水墨武器：鱼骨墨针、流叶回锋、爪痕剑气、铃线追魂、泼墨团、扇骨游刃、残墨雾、水纹震、符墨阵、雷墨丝、回游鱼刃、狮吼墨波。
- 12 把武器均支持 Lv.1～Lv.7 数值成长、专属行为与终极变化；DEV LAB 会直接读取武器数据自动生成控制项。
- 12 把武器的局内表现已按设定图区分：鱼骨飞白、旋叶弧锋、朱红爪痕、淡金铃线、墨核墨花、扇骨游刃、低透明墨雾、青碧水纹、朱红符阵、青白雷丝、回游鱼刃与狮吼墨波。
- 两个固定装置：镇纸飞刃、纸伞震阵。
- 小墨灵、疾影鼠、石墨兽、墨羽鸦、铃纸灵、残墨妖与赤印精英。
- 两阶段首领“泼墨狸将”：扇形泼墨弹 + 毛笔落地危险墨痕。
- 三选一升级、Lv.7 终极变化、商店、奇遇、宝箱、暂停、结算和本地存档。
- 独立开发测试面板，支持改数值、刷怪、跳阶段、召唤 Boss 与保存 Build。

## 运行

在本目录启动任意静态文件服务器后访问 `index.html`。也可以直接双击页面运行；静态服务器模式在浏览器兼容性上更稳定。

## 操作

- 电脑：WASD / 方向键移动，`P` 或 `Esc` 暂停。
- 手机：拖动左下角虚拟摇杆。
- 武器自动攻击；升级、商店和事件界面会自动暂停战斗。

## 三角色技能树 V2

- 首页点击“成长”进入技能树，可在喵小白、赤痕、青砚之间切换；使用正式存档中的铜钱解锁节点。
- 技能树进度独立保存在浏览器 `localStorage` 的 `meowGardenGrowth.v2` 中，使用节点 ID 而不是显示名称判断逻辑。
- 重置当前角色会全额返还该角色已投入的铜钱；专属挑战完成记录会保留，最终突破可在重置后重新选择。
- 挑战印记解锁后可直接从节点进入专属挑战：喵小白单武器通关、赤痕最终命通关、青砚无召唤通关。完成后开放最终突破。
- 武器大师、血墨护身、死斗印记、不屈残火、聚灵、余魂、墨阵共鸣等 7 张专属卡会按节点与局内条件进入三选一升级池，不是空白解锁。
- VFX Tier 与伤害判定分离：武器 Lv.1～2 为 Tier 1、Lv.3～6 为 Tier 2、Lv.7 为 Tier 3；召唤在 Lv.3 / Lv.5 发生对应形象与特效进化。
- 局外成长不会写入 DEV Build 槽；DEV 测试资源也不会自动解锁正式技能树。

## 开发测试

- 首页点击“开发测试”，或访问 `index.html?dev=1`。
- 点击右上角“DEV ⚙”打开或关闭开发测试台；面板打开时默认暂停战斗。
- “ANIMATION TEST” 可独立查看移动、攻击、受击、死亡四种状态，以及向上、向下、向左、向右四个方向，并切换 0.5x / 1x / 2x 预览速度。
- DEV LAB 支持运行速度、无敌、无限刷新、玩家属性、全部武器/被动/装置等级、刷怪、Boss、流程阶段、测试预设、实时统计、Build 保存/导入以及战场清理。
- Build 的 Slot 1～3 与当前配置保存在浏览器 `localStorage` 中，仅在当前浏览器和当前页面来源下可用。
- 开发模式数据不会写入正式存档。

## 喵小白动画资源

- 移动帧位于 `assets/characters/xiaobai/move/`，按 `down`、`up`、`left`、`right` 分目录，每个方向使用 `01.png`～`08.png`。
- 攻击、受击和死亡帧分别位于 `attack/`、`hit/`、`death/`；每个方向使用精简后的 5、3、6 帧，并按 12、12、8 FPS 播放。
- 动画优先级为死亡、受击、攻击、移动；死亡动画播放结束后再进入结算。页面会预加载全部帧，单帧缺失时自动回退，不会中断游戏。

## 首页与视觉方向

- 首页采用“Q 版动漫 + 水墨表现”：PC 为左侧功能、中央角色、右侧角色与章节信息；手机端调整为角色、章节、主按钮、功能入口的纵向结构。
- 首页入口包括角色、成长、武器、挑战、设置和存档；没有加入联网大厅、商城、活动或社交入口。
- 角色界面可查看并选择三名角色；赤痕、青砚使用正式立绘，局内暂用独立水墨占位形象，等待后续建模方案。

## 表现层替换

- `game-data.js` 中提供 `LEGACY_ASSET_MAP`，正式动漫水墨素材使用新的 `art_key`，旧素材保留为 `fallback_art` / `legacy_art`。
- 页面会优先尝试加载新素材；文件尚未制作时自动回退到现有素材，不会中断游戏。角色数据区分 `portrait_art` 与 `combat_art`，方便后续单独替换局内模型。
- `INK_FX` 为统一水墨 FX 接口，当前提供笔锋、墨花、流动墨线、水纹、墨池和退墨等表现类型；运行时追加 `vfx-tier-1/2/3` 表现类，不改变伤害、命中或冷却逻辑。
- 角色移动、敌人退墨死亡与范围特效的动画只作用于内部表现层，不会再覆盖世界坐标；这样可避免角色抖动、敌人死亡飞图和命中特效出现在地图原点。
- 后续替换素材时优先在 `assets/art/` 增加对应新文件，或修改数据中的 `art` / `fallback_art` / `fx_id`，不要用中文显示名判断战斗规则。
