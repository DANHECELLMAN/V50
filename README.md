# 喵勇者：花园大作战

根据《猫咪轻量动作肉鸽_总体策划案 V1.0》制作的首个可玩纵向切片。项目为零依赖 HTML5 Canvas 游戏，可直接双击 `index.html` 运行。

## 已完成内容

- 只移动、自动瞄准和自动攻击；支持 WASD、方向键和触屏虚拟摇杆
- 默认 8 分钟完整节奏：快速成型 → 中压构筑 → 高压怪潮 → Boss
- 4 把武器、8 个被动、2 个固定装置，升级固定三选一并有 2 次刷新
- 6 类普通/特殊敌人、精英怪、两阶段 Boss“暴走扫地机”
- 经验球、金币、治疗、宝箱、商人、随机事件和结算战报
- 响应式横竖屏布局、本地最高存活时间与猫币存档
- 纯 Canvas Q 版占位美术与 Web Audio 合成反馈，不依赖外部素材

## 运行

直接打开 `index.html`，或在本目录启动任意静态文件服务器。

开发验收时可给地址追加 `?dev=1`，把单局缩短为 90 秒，Boss 会在第 60 秒登场。正式玩法不带该参数，单局为 8 分钟。

## 操作

- 电脑：WASD / 方向键移动，`P` 或 `Esc` 暂停
- 手机：拖动左下角虚拟摇杆
- 武器自动攻击；升级、商店、事件界面会自动暂停战斗

## 当前版本边界

本次交付对应策划案 P1 纵向切片，优先验证核心移动手感、怪潮节奏、Build 选择和 Boss 可读性。三角色、其余两张主线地图、专属挑战、局外成长树、广告及完整首发内容池属于后续里程碑。
