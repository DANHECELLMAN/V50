# 喵勇者：墨韵庭院

根据动漫水墨风系列规格持续开发的 HTML5 可玩原型，当前用于验证玩法、Build、数值、Boss 与怪潮。

## 技术结构

- 不使用 Canvas；战斗场景、角色、敌人、弹体、掉落与特效全部使用 HTML DOM + CSS 呈现。
- 角色、武器、敌人、Boss、900 秒 Timeline、场景分层与美术引用集中在 `game-data.js`，数值逻辑与表现资源分离。
- 美术图片位于 `assets/art/`，可以在不改伤害公式的情况下替换。
- 零第三方依赖，使用静态服务器即可运行。

- 三角色均已接入“专属自动武器 + 三个同时存在的小技能 + 一个大招”，主动技能只使用 CD，不消耗蓝量。

## 运行

在本目录启动任意静态文件服务器后访问 `index.html`。也可以直接双击页面运行；静态服务器模式在浏览器兼容性上更稳定。

## 操作

- 电脑：WASD / 方向键移动，`Q` / `E` / `R` 释放三个小技能，`F` 释放大招；数字键 `1`～`4` 也可对应释放，`P` 或 `Esc` 暂停。
- 手机：拖动左下角虚拟摇杆，点击右下角四个水墨技能按钮释放主动技能。
- 武器自动攻击；升级、商店和事件界面会自动暂停战斗。

## 三角色技能树 V3

- 首页点击“成长”进入技能树，可切换角色并选择“基础修行 / 专属武器 / 主动技能 / 大招”等路线；点击路线卡片后会打开独立升级窗口，节点与详情不会再和主页面互相挤压。
- 技能树使用独立的“修行点 SP”，正常结算按角色等级与胜负发放；DEV 局不发放，也不会污染正式成长。
- 技能树进度保存在浏览器 `localStorage` 的 `meowGardenGrowth.v3` 中；旧 `v2` 数据会安全迁移并发放基础修行点。
- 重置当前角色会全额返还该角色投入的修行点；互斥终局节点可在重置后重新选择。
- 青砚技能树可永久扩充“万灵图录”、解锁阵器入池，并在详情区设置两种偏好召唤；偏好只改变随机权重，不会排除其他已解锁召唤。
- 局外成长不会写入 DEV Build 槽；DEV 测试资源也不会自动解锁正式技能树。

## 开发测试

- 首页点击“开发测试”，或访问 `index.html?dev=1`。
- DEV LAB 的“VISUAL / ASSET TEST”可打开独立美术验收台；也可直接访问 `index.html?dev=1&visual=1`。
- 美术验收台支持切换角色/敌人/Boss、move/attack/hit/death、四方向、FPS、scale、anchor、白/灰/游戏背景、1/10/50 单位压力预览及单独 VFX 播放。
- “FLOW / EVENTS”提供 66日、44日、29日、14日、1日与0日/Boss跳转；跳转会同步 Timeline 状态，避免补触发旧事件。
- 点击右上角“DEV ⚙”打开或关闭开发测试台；面板打开时默认暂停战斗。
- “ANIMATION TEST” 可独立查看移动、攻击、受击、死亡四种状态，以及向上、向下、向左、向右四个方向，并切换 0.5x / 1x / 2x 预览速度。
- DEV LAB 的“ACTIVE SKILLS”可直接调整当前角色专属武器 Lv.1～Lv.7、强制释放四个技能并重置全部技能 CD。
- DEV LAB 支持运行速度、无敌、无限刷新、玩家属性、全部武器/被动/装置等级、刷怪、Boss、流程阶段、测试预设、实时统计、Build 保存/导入以及战场清理；Build JSON 已包含专属武器等级。
- Build 的 Slot 1～3 与当前配置保存在浏览器 `localStorage` 中，仅在当前浏览器和当前页面来源下可用。
- 开发模式数据不会写入正式存档。

## 喵小白动画资源

- 移动帧位于 `assets/characters/xiaobai/move/`，按 `down`、`up`、`left`、`right` 分目录，每个方向使用 `01.png`～`08.png`。
- 攻击、受击和死亡帧分别位于 `attack/`、`hit/`、`death/`；每个方向使用精简后的 5、3、6 帧，并按 12、12、8 FPS 播放。
- 动画优先级为死亡、受击、攻击、移动；死亡动画播放结束后再进入结算。页面会预加载全部帧，单帧缺失时自动回退，不会中断游戏。

## 首页与视觉方向

- 首页采用“Q 版动漫 + 水墨表现”：PC 为左侧功能、中央角色、右侧角色与章节信息；手机端调整为角色、章节、主按钮、功能入口的纵向结构。
- 首页入口包括角色、成长、武器、挑战、设置和存档；没有加入联网大厅、商城、活动或社交入口。
- 角色界面可查看并选择三名角色；赤痕、青砚使用正式立绘，局内暂用独立水墨占位形象，等待后续建模方案。

## 资源目录与表现层替换

- `game-data.js` 中的 `ASSET_MANIFEST` 是角色、敌人与 Boss 的统一资源入口，包含 `id/name/sprite/animations/directions/fps/scale/anchor/pivot/collisionRadius`；`LEGACY_ASSET_MAP` 继续作为旧素材兼容层。
- 角色资源放在 `assets/characters/<id>/<state>/<direction>/01.png...`；敌人与 Boss 建议分别放在 `assets/enemies/<id>/...`、`assets/bosses/<id>/...`，状态统一为 `move/attack/hit/death`。
- 场景按 `assets/scenes/first-cycle/ground|obstacle|decoration|landmark|overlay/` 分层；缺少墨岩、枯竹、石径、浅溪、残亭、荷塘、断桥或纸裂图片时使用当前庭院背景，不会报错。
- 页面会优先尝试加载新素材；文件尚未制作时自动回退到现有素材，不会中断游戏。角色数据区分 `portrait_art` 与 `combat_art`，方便后续单独替换局内模型。
- `VFX_LIBRARY` 使用稳定资源 ID：`ink_hit_small`、`ink_hit_large`、`cyan_slash`、`red_slash`、`death_ink`、`warning_circle`、`warning_cone`、`warning_line`、`ink_pool`；旧 `INK_FX` ID 会自动映射兼容。
- 角色移动、敌人退墨死亡与范围特效的动画只作用于内部表现层，不会再覆盖世界坐标；这样可避免角色抖动、敌人死亡飞图和命中特效出现在地图原点。
- 后续替换素材时优先在 `assets/art/` 增加对应新文件，或修改数据中的 `art` / `fallback_art` / `fx_id`，不要用中文显示名判断战斗规则。
